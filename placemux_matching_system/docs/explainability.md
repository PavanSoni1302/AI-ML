# Recommendation Explainability

## Objective

Provide transparent explanations for every recommendation generated by the AI engine.

## Inputs

- recommendations.csv
- students.csv
- jobs.csv

## Outputs

- recommendation_explanations.csv
- review_queue.csv

## Explanation Rules

- Python skill comparison
- Machine Learning skill comparison
- SQL skill comparison
- Communication skill comparison
- AI Trust verification

## Review Queue

Recommendations with scores between 70 and 84 are sent for manual review.

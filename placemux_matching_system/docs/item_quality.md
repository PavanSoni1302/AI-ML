# Item Bank Quality Support

## Objective

Identify weak or incomplete job postings before they are published.

## Inputs

- jobs.csv

## Outputs

- weak_items.csv
- recruiter_dashboard.csv

## Validation Rules

- Python threshold < 50
- ML threshold < 50
- SQL threshold < 50
- Communication threshold < 50
- Experience requirement = 0

## Purpose

Provide recruiters and administrators with a quality report for job postings before publishing.

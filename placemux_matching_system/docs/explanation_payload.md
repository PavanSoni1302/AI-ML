# Explanation Payload

Purpose:
Provide transparent reasoning behind every student-job match.

Payload Fields:

- Candidate Name
- Job Role
- Match Score
- Skill Gaps
- Recommendation Reason
- Final Decision

Example:

Candidate: Pavan

Job: AI Engineer

Score: 52

Reason:
Python exceeds requirement by 10
ML exceeds requirement by 7
SQL exceeds requirement by 15
Communication exceeds requirement by 10

Decision:
Strong Match

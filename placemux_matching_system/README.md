# PlaceMux Matching System

## Overview

PlaceMux Matching System is an AI-powered candidate-job matching platform that recommends suitable jobs to students and ranks candidates for companies based on skill matching and threshold validation.

## Features

* Candidate Ranking
* Job Recommendation
* Threshold Validation
* Match Explainability
* Search & Discovery
* Conversion-Tuned Matching
* Low-Fit Warning System
* Quality Validation
* Flask API Integration

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Flask
* Joblib

## Project Structure

data/
